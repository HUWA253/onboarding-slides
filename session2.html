今日使う用語⏱ 目安5分

覚えておきたい言葉

Node.js / npm
JavaScriptをPC上で動かす仕組みと、そのための道具箱（ライブラリ）を管理するツール
clone（クローン）
GitHub上のリポジトリを、自分のPCにまるごとコピーしてくること
clasp（クラスプ）
自分のPCとGoogleアプリスクリプト(GAS)をつなぐための専用ツール
ローカルサーバー
自分のPCの中だけで動く、お試し用のWebサーバー。ここに向けてブラウザでアクセスして画面を確認する

実践1⏱ 目安3分

Node.jsが入っているか確認

ターミナル（黒い画面）を開いて、以下を打ってみてください。

node --version npm --version
バージョン番号が表示されればOK。「command not found」のようなエラーが出たら、その場で入れ方を確認しましょう。

実践2⏱ 目安5分

VSCodeをインストールする

1https://code.visualstudio.com/ からダウンロード
2インストーラーを実行。基本は全部「Next」でOK
3起動して、フォルダを開けることを確認する
これが今後コードを読み書きするための「本物のエディタ」です。メモ帳とはここでお別れです。

実践3⏱ 目安5分

Gitをインストールする

1https://git-scm.com/download/win を開き、インストーラーをダウンロード
2インストーラーを実行。基本は全部「Next」でOK
3PowerShell（またはVSCode内のターミナル）で確認
git --version
4初回だけ、自分の名前とメールアドレスを設定
git config --global user.name "自分の名前" git config --global user.email "自分のメールアドレス"
前回はブラウザだけでPRを出しましたが、実際のコードを触うにはローカルにもGitが必要です。WSLもUbuntuも不要です。

実践4⏱ 目安5分

プロジェクトをcloneする

1作業したいフォルダに移動する（例: cd ~/projects）
2以下のコマンドでリポジトリを持ってくる
git clone （リポジトリのURL）
3できたフォルダをVSCodeで開く
cd （フォルダ名） code .

実践5⏱ 目安3分

必要な道具箱をインストール

プロジェクトが使っているライブラリ一式をまとめて入れます。VSCode内のターミナル（メニューの「Terminal」→「New Terminal」）から実行できます。

npm install
少し時間がかかります。エラーが大量に出なければ大丈夫です。

実践6⏱ 目安5分

自分のGoogleアカウントでログイン

npx clasp login
  • ブラウザが開くので、自分のGoogleアカウントでログイン
  • 権限の許可を求められたら「許可」を選ぶ
ここで使うのは自分専用の開発環境用アカウントです。サークル共有アカウントではありません。

実践7⏱ 目安5分

自分専用のGASプロジェクトを作る

cd src npx clasp create --type webapp --title "自分の名前_dev"
これで自分だけが触れる、練習用のGoogleアプリスクリプトのプロジェクトが1つできました。他の人のものとは完全に別物です。

実践8（メイン）⏱ 目安10分

自分のPCで画面を表示する

cd .. npm run dev

表示されたURL（http://localhost:5173 など）をブラウザで開いてください。

アプリの画面が表示されたら今日は成功です！コードを保存すると、この画面も自動で変わるようになっています。
